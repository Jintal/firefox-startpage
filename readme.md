# New Tab for Firefox Browser

This repository contains a custom `index.html` file that you can use as a new tab page for your Firefox browser.

## How to Use

1. **Clone this repository**:

2. **Set as Firefox New Tab**:
   - Download [`New Tab Override`](https://addons.mozilla.org/en-US/firefox/addon/new-tab-override/) extension.
   - Go to settings of the extension and add the path for `index.html` after choosing `local file`.

3. **Install JetBrainsMono Nerd Font (Optional)**:
   - The page uses **JetBrainsMono Nerd Font** for the proper display of text.
   - Install the font on your system if you want to fully experience the design. You can download it from [Nerd Fonts](https://www.nerdfonts.com/).

## Customization

You can easily customize the page:

- **Edit the Links**: Replace the `#link1`, `#link2`, etc., with actual URLs that you want to link to.
- **Modify the Greeting**: Change the greeting text or add dynamic content.
- **Add More Categories**: Feel free to duplicate and modify the `<div class="nav-category">` block to add more sections with links.
- For more information visit [`r/startpages`](https://www.reddit.com/r/startpages/wiki/index/)
